# IBM Data Science Capstone — SpaceX Falcon 9 Landing Prediction

**Author:** Abdul Rehman

This repository contains the project workflow for exploring Falcon 9 first-stage landing outcomes, including data preparation, EDA, SQL queries, mapping, dashboard code, and predictive modelling.

## Files
- `notebooks/SpaceX_Capstone_End_to_End.ipynb` — analysis notebook
- `sql/queries.sql` — SQL analysis queries
- `app.py` — Plotly Dash dashboard starter
- `requirements.txt` — Python dependencies

## Run
Install dependencies with `pip install -r requirements.txt`, place the official course file `dataset_part_2.csv` in a `data/` folder, then run the notebook from top to bottom. Start the dashboard with `python app.py`.

**Reproducibility note:** Actual EDA charts, SQL result tables, map output, and model metrics must be generated by running the notebook against the official course dataset. This repository does not claim those outputs have already been executed.
